Sin conexión

Este navegador no puede hablar con el Arduino por USB. Abre este archivo en Google Chrome o Microsoft Edge (en computador). Mientras tanto puedes usar «Probar sin Arduino».

Conecta el Arduino para empezar

Conecta el cable USB, pulsa «Conectar Arduino» y elige el puerto (suele llamarse «USB-SERIAL CH340»). Si no tienes el Arduino a mano, pulsa «Probar sin Arduino».
